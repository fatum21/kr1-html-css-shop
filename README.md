# Lumen — каталог настольных ламп

Учебный проект по дисциплине **«Фронтенд и бэкенд разработка»**.

## Контрольная работа №1

**Тема:** «HTML и CSS: разработка многостраничного сайта».

Проект представляет собой многостраничный HTML/CSS-сайт небольшого каталога
настольных ламп Lumen. Вёрстка выполнена без CSS-фреймворков; JavaScript
используется минимально — для модального окна и сообщений об отправке форм.

## Ссылка на опубликованный проект

- **GitHub Pages:** https://fatum21.github.io/kr1-html-css-shop/
- **Репозиторий:** https://github.com/fatum21/kr1-html-css-shop

## Краткое описание проекта

Lumen — каталог настольных ламп для дома и работы. На сайте представлены
четыре модели, страница товара с таблицей характеристик, форма заявки и
контактная информация. Общая структура страниц, навигация, карточки товаров
и форма оформлены в едином минималистичном стиле.

## Структура проекта

```
kr1-html-css-shop/
├── index.html          # главная страница: hero, популярные модели, преимущества
├── catalog.html        # каталог: фильтры и сетка карточек

├── order.html          # форма оформления заявки

├── css/

├── js/
│   └── main.js         # модальное окно и сообщения об отправке форм
├── images/             # SVG-изображения ламп и favicon
├── README.md
└── .gitignore
```

## Используемые технологии

- **HTML5** — семантическая разметка (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- **CSS3** — внешний файл стилей, CSS-переменные в `:root`, Flexbox, CSS Grid, состояния `:hover` / `:focus-visible`.
- **БЭМ** — базовое именование классов: блок, элемент, модификатор.
- **Позиционирование** — `sticky` у шапки и фильтра, `absolute` у бейджей, `relative` у карточек, `z-index` у шапки.
- **JavaScript (минимально)** — открытие и закрытие модального окна, сообщение об отправке формы.
- **SVG** — векторные изображения товаров и favicon.

## Реализованные обязательные элементы

- **Семантика:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`; один `main` на страницу.
- **Навигация:** единое меню между всеми страницами и якорные ссылки
  (`index.html#popular`, `index.html#advantages`); в подвале главной есть `id="contacts"`.
- **Карточки товаров** как `article` с изображением, названием, описанием, ценой, бейджем и кнопкой.
- **Таблица:** характеристики товара с `caption`, `thead`, `tbody`, `th` и `td`.
- **Форма:** имя, e-mail, телефон, модель, комментарий, согласие и кнопка отправки;
  используются `label` + `for`/`id`, атрибуты `name`, `required`, `type="email"`.
- **Модальное окно** на `<dialog>` с открытием и закрытием через `js/main.js`.
- **CSS:** внешний файл, переменные в `:root`, состояния `:hover` / `:focus-visible`.
- **Flexbox и Grid:** шапка и кнопки на Flexbox; карточки, каталог, форма и подвал на Grid.
- **БЭМ:** `product-card`, `product-card__title`, `product-card__badge--accent`,
  `site-nav__link--active`, `order-form__field` и т. д.
- **Позиционирование:** `sticky` у шапки и фильтра, `absolute` у бейджей,
  `relative` у карточек товара, `z-index` у шапки.
- **Адаптивность:** сетки перестраиваются в одну колонку на планшетах и смартфонах.

## Самостоятельные доработки

1. **Собственная визуальная концепция** — минималистичный каталог Lumen с единой палитрой и типографикой.
2. **Четыре модели ламп** — Lumen One, Lumen Arc, Lumen Mini и Lumen Classic.
3. **Бейджи и состояния карточек** — «Хит», «Новинка», hover-эффект и тени.
4. **Блок фильтров** — статическая форма с категориями и диапазоном цены.
5. **Страница товара** — характеристики, условия покупки и кнопка заявки.
6. **Модальное окно заявки** — нативный `<dialog>` с закрытием по кнопке, Esc и клику по фону.
7. **Сообщение об успешной отправке** — выводится после заполнения формы.
8. **Хлебные крошки** на внутренних страницах.
9. **Адаптивная навигация и сетки** — корректное отображение на мобильных устройствах.
10. **Доступность** — skip-link, видимый фокус, `aria-current`, подписи полей.
11. **SVG-изображения** — локальные иллюстрации без внешних зависимостей.

# ТехноМарт — многостраничный сайт интернет-магазина электроники

Учебный проект по дисциплине **«Фронтенд и бэкенд разработка»**.

## Контрольная работа №1

**Тема:** «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина электроники
«ТехноМарт»: главная страница, каталог с фильтрами, карточка товара, страница
оформления заявки и страница контактов. Проект выполнен без CSS-фреймворков;
JavaScript используется только для минимальной логики модального окна.

## Краткое описание проекта

«ТехноМарт» — каталог электроники (ноутбуки, смартфоны, аудио, носимые устройства,
игровые консоли, аксессуары). Сайт состоит из нескольких связанных страниц с единой
навигацией, якорными ссылками, карточками товаров, таблицами характеристик и
сравнения, формами заявки и обратной связи, модальным окном и общей визуальной
концепцией. Вёрстка построена на семантической разметке, Flexbox и CSS Grid,
стилизация — на CSS-переменных, БЭМ-классах и состояниях `:hover` / `:focus-visible`.

## Используемые технологии

- **HTML5** — семантическая разметка (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- **CSS3** — внешний файл стилей, CSS-переменные (`:root`), Flexbox, CSS Grid, состояния `:hover` / `:focus-visible`.
- **БЭМ** — базовое именование классов (блок, элемент, модификатор).
- **Позиционирование** — `relative`, `absolute`, `sticky`, `fixed`, `z-index`.
- **JavaScript (минимально)** — открытие/закрытие модального окна на `<dialog>`.
- **SVG** — векторные изображения товаров и интерфейса (полностью офлайн).

## Реализованные обязательные элементы

- **Семантика:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, один `main` на страницу.
- **Навигация:** единое меню между всеми страницами и якорные ссылки
  (`index.html#advantages`, `index.html#popular`, `index.html#contacts`).
- **Карточки товаров** как `article` с названием, описанием, ценой, бейджем и кнопкой «Подробнее».
- **Таблицы:** характеристики товара и сравнение моделей (`caption`, `thead`, `tbody`, `th`, `td`).
- **Форма:** имя, e-mail, телефон, товар, комментарий, согласие и кнопка; `label` + `for`/`id`, `name`, `required`, `type="email"`.
- **Модальное окно** на `<dialog>` с открытием/закрытием через `js/main.js`.
- **CSS:** внешний файл, переменные в `:root`, состояния `:hover`/`:focus-visible`, недоступное состояние кнопок.
- **Flexbox и Grid:** меню и шапка на Flexbox, сетки карточек, каталога с фильтрами и подвала — на Grid.
- **БЭМ:** `product-card`, `product-card__title`, `product-card--discount`, `site-nav__link--active`, `order-form__field` и т. д.
- **Позиционирование:** `relative` у карточки товара, `absolute` у бейджей, `sticky` у шапки и фильтра, `fixed` у кнопки «Наверх», `z-index` у модального окна и фиксированной кнопки.

## Самостоятельные доработки

Помимо базовой части реализованы дополнительные улучшения:

1. **Собственная визуальная концепция** — фирменный стиль «ТехноМарт» (палитра, тени, радиусы, типографика) через CSS-переменные.
2. **Дополнительная страница** `category.html` — отдельная страница категории «Ноутбуки» со своими фильтрами.
3. **Расширенный каталог** — 12 товаров в каталоге и 6 в категории.
4. **Улучшенные карточки** — бейджи «Новинка», «Хит», «Скидка −%», рейтинг, старая цена, БЭМ-модификаторы `product-card--hit`, `--discount`, `--featured`.
5. **Хлебные крошки** на всех внутренних страницах.
6. **Sticky-фильтр каталога** и фиксированная кнопка «Наверх».
7. **Блоки отзывов и FAQ** (на `<details>`/`<summary>`) на главной и на странице товара.
8. **Расширенная таблица сравнения** трёх моделей ноутбуков с подсветкой рекомендуемой колонки.
9. **Улучшенная форма** — radio-группа выбора оплаты, подсказки, состояние ошибки, комментарий, количество, город доставки.
10. **Улучшенное модальное окно** на нативном `<dialog>` (закрытие по Esc и по клику на фон).
11. **Доступность** — «skip-link», видимый фокус, `aria`-атрибуты, `visually-hidden` подписи, поддержка `prefers-reduced-motion`.
12. **Аккуратная работа с изображениями** — локальные SVG с атрибутами `width`/`height` и `loading="lazy"`.
13. **Промо-баннер и блок «Как это работает»** — дополнительные UI-компоненты с собственным оформлением.
